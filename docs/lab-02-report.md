# ЛР2. Первая главная страница приложения TemkaStar

## 1. Название проекта и цель главной страницы

**Проект:** TemkaStar — сайт для открытия кейсов с Telegram-подарками.
**Цель главной страницы:** познакомить пользователя с приложением и показать список доступных кейсов, разбитых по категориям (бонусные, звёздные поводы, праздничный дроп, эксклюзив).

## 2. Краткое описание выполненной вёрстки

Главная страница состоит из шапки (лого, навигация, кнопка «Авторизация»), первого экрана с баннерами, пяти секций с кейсами и подвала. Каждая секция содержит заголовок и сетку карточек. Карточка кейса показывает картинку, название и стоимость в монетах.

## 3. Описание mock-данных и их полей

Mock-данные лежат в `src/mocks/casesMock.js`. Функция `fetchCasesMock` возвращает Promise с задержкой 700 мс, имитируя ответ сервера. Данные берутся из `src/data/cases.js`.

Каждый кейс имеет поля:
- `id` — уникальный идентификатор;
- `name` — название кейса;
- `cost` — стоимость в монетах;
- `img` — путь к картинке.

Массивы: `bonusCases`, `starCases`, `holidayDrop`, `starOccasions`, `exclusiveCases`.

## 4. Список созданных компонентов

- `Header` — шапка приложения.
- `Footer` — подвал.
- `HeroSection` — первый экран с баннерами.
- `CaseSection` — секция с заголовком и сеткой кейсов.
- `CaseCard` — карточка одного кейса.
- `SectionTitle` — заголовок секции.
- `HomePage` — страница, собирающая всё вместе.

## 5. Где используется useState

В `HomePage`:
- `cases` — хранит данные, пришедшие из mock-источника;
- `isLoading` — хранит признак загрузки;
- `error` — хранит сообщение об ошибке.

## 6. Где используется useEffect

В `HomePage`. При открытии страницы запускается `fetchCasesMock()`. Пустой массив зависимостей `[]` гарантирует, что эффект выполнится один раз. Функция очистки помечает запрос неактуальным, если компонент размонтирован до его завершения.
