# temkastar

Учебное React-приложение — игровая платформа для открытия кейсов с Telegram-подарками, апгрейда предметов и вывода выигрыша.

## Назначение проекта

Пользователь открывает кейсы за деньги, получает случайные Telegram-подарки, может улучшить их на более дорогие (апгрейд), вывести в свой Telegram-аккаунт. Развивается поэтапно в рамках курса по фронтенд-разработке.

## Статус

Выполнено задание №1:

- развёрнут проект на Vite + React + JavaScript;
- описана предметная область и основная сущность `Case`;
- зафиксированы будущие страницы, пользовательские сценарии и границы первой версии.

Backend, Redux Toolkit, маршрутизация, формы, оплата и Telegram API будут добавлены в следующих заданиях.

## Запуск проекта

Установить зависимости:

```bash
npm install
```

Запустить режим разработки:

```bash
npm run dev
```

После запуска открыть адрес, который покажет Vite, обычно `http://localhost:5173`.

## Проверка проекта

Проверка production-сборки:

```bash
npm run build
```

Проверка линтером:

```bash
npm run lint
```

Локальный просмотр production-сборки:

```bash
npm run preview
```
